# Checklist

- [x] 项目可在 Godot 4.x 中打开并运行主场景
- [x] 视口为 256×240 且窗口整数倍放大显示
- [x] 玩家可左右奔跑、跳跃并自然下落
- [x] 玩家在地面与空中均可挥剑攻击
- [x] 玩家可吸附可攀爬墙体、上下攀爬并跳离
- [x] 玩家受击时扣血、向后击退并有短暂无敌帧
- [x] 玩家生命值归零或掉入坑洞判定死亡，命数减一并从重生点重生
- [x] 命数耗尽进入游戏结束流程
- [x] 剑击命中敌人可扣血/消灭敌人并加分
- [x] 敌人接触玩家可造成伤害
- [x] 奔跑杂兵生成后向玩家方向移动
- [x] 飞行杂兵按正弦轨迹移动
- [x] 敌人由生成触发区随玩家推进生成，且通过对象池复用（无运行时反复实例化/销毁）
- [x] 关卡包含起点、平台段落、可攀爬墙体、坑洞，可从起点完整通行至 Boss 区域
- [x] 摄像机水平跟随玩家且受关卡边界限制
- [x] 进入 Boss 区域触发 Boss 战并显示 Boss 血条
- [x] Boss 有移动与攻击行为，可被玩家击败
- [x] 击败 Boss 后进入通关结算画面并显示分数
- [x] HUD 正确显示玩家血条、命数、分数、倒计时
- [x] 倒计时归零判定玩家死亡一次
- [x] 标题画面按开始键可进入第一关
- [x] 玩家与敌人的状态切换均通过 FSM 实现
